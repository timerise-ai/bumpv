# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-25

First release: the release procedure in the layout of the Timerise skill standard, with its edits kept in
agreement across every place the version appears.

### Added

- `SKILL.md`: the procedure from a clean tree to a verified annotated tag, with six critical facts, six hard
  rules, the invocation table, the quick start and the reference directory.
- `references/version-sources.md`: the version-source table for Node, Rust, Python, Go, PHP, Ruby, .NET and
  Dart, the last tag and its prefix, the commit range, disagreeing sources and monorepos.
- `references/bump-level.md`: the Semantic Versioning rule, the commit-type mapping, first releases and
  four worked examples.
- `references/release-files.md`: the manifest, the changelog, the README current-release line and the
  context-file note, after the repository's own release convention.
- `references/commit-and-tag.md`: staging by name, the release commit without attribution, the annotated
  tag and its check, and the handover of the push.
- `references/provenance.md`: what the audit fixed, what was kept deliberately and what was added.
- `README.md`, `CLAUDE.md`, `LICENSE`, `evals/prompts.md` and the agent eval workflow caller.
